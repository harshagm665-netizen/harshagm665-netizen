```

     ^                                                                    |
     +---------------------- Encoder Odometry <-- 50 Hz PID Loop <--------+
```

```
+-------------------------------------------------------------+
|  Raspberry Pi 5  --  ROS2 Jazzy                              |

|  |  Localization|->|  Global Plan |->|  Local Planner   |    |
|  +------+-------+  +--------------+  +--------+---------+    |
|         |                                      |              |
|    /tf: map->odom                          /cmd_vel           |
```
